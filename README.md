# 📚 Balóchi Bongéji (بلوچی بنگیجی) - Studio Edition

An interactive, modern desktop learning application designed to teach Balochi alphabets, phonetics, examples, and native audio pronunciations (_Tawar_).

---

## 🌟 Key Features

- **Comprehensive Alphabet Suite:** Learn all 29 Balochi letters with phonetic sounds and example words.
- **Categorized Learning:** Filter by Consonants, Short/Long Vowels, and Compound Consonants.
- **Native Audio Playback:** Listen to authentic audio pronunciations (_Tawar_) for every letter.
- **Interactive Grid:** Quick navigation and step-by-step learning progression.
